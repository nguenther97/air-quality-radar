# AQR Roadmap

_Update this file whenever something changes — it feeds directly into the weekly digest email._

## In Progress
- Weekly digest email to marketing, paid media, and CEO (this workflow)
- Teams channel notifications for new alerts (GitHub → Teams via Power Automate)

## On Deck
- Population-weighted opportunity scoring in alert titles (e.g. "Los Angeles, CA — pop. 3.9M")
- Campaign brief template pre-filled in each alert issue body
- Dashboard filtering by region or tier
- Adjustable alert thresholds via config file (no code change required)

## Exploring
- Additional Canadian data sources to fill remote community coverage gaps
- Inventory-aware prioritization (cross-referencing Amazon stock levels with elevated markets)
- Close-the-loop tracking: linking AQR-triggered campaigns to downstream sales lift
- Local dev mode for faster dashboard UI iteration (`npm run preview`)
